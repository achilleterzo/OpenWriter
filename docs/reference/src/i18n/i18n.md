# src/i18n

Interface translations of the renderer.

## index.js

Source: [`src/i18n/index.js`](../../i18n/index.js)

Translation runtime for the UI. Keys are the English texts (source language and fallback); catalogs are JSON files under [`src/i18n/locales/`](locales/) shared with the main process. A key with no translation shows the English text.

- `t(key, params)`: translation with `{name}` placeholder interpolation; a `|context` suffix on a key (e.g. `"Medium|width"`) distinguishes meanings and never shows.
- `tp(count, forms, params)`: plurals through `Intl.PluralRules`, with the English forms `{ one, other }` and the catalog entry indexed by the "other" form.
- Languages: English (the default), Italian, Spanish, French, German, Portuguese; `auto` resolves the system language, `pseudo` wraps translated text in `⟦ ⟧` for coverage checks.
- The preference is stored through [preferences.js](../lib/preferences.js.md) (`openwriter.language`), defaulting to the system language. On change the window reloads (session, drafts and tabs are restored) and a session flag reopens the settings screen (`AFTER_LANGUAGE_RELOAD_KEY`); the main process receives the locale via `setLocale`, so menus, dialogs and errors follow the same language.
- `initLanguage()` aligns the document language and the main process at startup; `subscribeLanguage` listens for changes; `getLanguage` and `getLanguagePreference` read the current language and the preference.
- `languageEnglishName()`: the English name of the interface language, which is what goes into the prompts ("Reply in Italian").
- Format helpers on the active locale: `intlLocale`, `formatDateTime`, `formatNumber`, `languageName`.
