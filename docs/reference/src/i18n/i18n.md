# src/i18n

Interface translations of the renderer.

## index.js

Source: [`src/i18n/index.js`](../i18n/index.js)

Translation runtime: loads the active locale, exposes `t(key, params)` used by every component, and handles the language-reload flow when the interface language changes (the app reopens the settings screen after the reload). Locales are JSON files under `src/i18n/locales/`.
