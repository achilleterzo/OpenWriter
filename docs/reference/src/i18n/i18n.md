# src/i18n

Interface translations of the renderer.

## index.js

Source: [`src/i18n/index.js`](../../i18n/index.js)

Translation runtime for the UI. Keys are the English texts (source language and fallback); catalogs are JSON files under [`src/i18n/locales/`](locales/) shared with the main process.

- `t(key, params)`: translation with `{name}` placeholder interpolation; a `|context` suffix on a key (e.g. `"Medium|width"`) distinguishes meanings and never shows.
- `tp(count, forms, params)`: plurals through `Intl.PluralRules`, catalog entries indexed by the "other" form.
- Languages: English (default), Italian, Spanish, French, German, Portuguese; `auto` resolves the system language, `pseudo` wraps translated text in `⟦ ⟧` for coverage checks.
- Preference stored in `localStorage` (`openwriter.language`). On change the window reloads (session, drafts, and tabs are restored) and a session flag reopens the settings screen (`AFTER_LANGUAGE_RELOAD_KEY`); the main process receives the locale via `setLocale`.
- Format helpers on the active locale: `intlLocale`, `formatDateTime`, `formatNumber`, `languageName`, `languageEnglishName`.
