# SettingsScreen.jsx

Source: [`src/components/SettingsScreen.jsx`](../../../../../src/components/SettingsScreen.jsx)

Full-screen settings container. Shows the General, Project, Appearance, AI, Skills (global library of writing skills, see [SkillsManager.jsx](SkillsManager.jsx.md)), and About sections; the screen is opened by the app menu command or after a language change requiring a reload.
