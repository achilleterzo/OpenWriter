# AboutSettings.jsx

Source: [`src/components/AboutSettings.jsx`](../../../../../src/components/AboutSettings.jsx)

The About section of the settings screen: the app icon with the name and the current version, the one-line description, and an Updates block with the same manual check as [AboutDialog.jsx](AboutDialog.jsx.md) (update available with a button opening the download page, otherwise "Check for updates" with the result). At the bottom, right-aligned, the developer and the licence.
