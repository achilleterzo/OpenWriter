# AiProviderSettings.jsx

Source: [`src/components/AiProviderSettings.jsx`](../../../../../src/components/AiProviderSettings.jsx)

Settings screen section for AI providers: choose among Ollama, Ollama Cloud, Codex, and Claude; configure endpoint and model names, reasoning effort levels, the assistant language, and the tool-chain limit; manage the Ollama Cloud API key (encrypted storage and deletion), run provider login flows, list models from the backend, and check provider status and installed CLIs.

The model is chosen with [ModelPicker.jsx](ModelPicker.jsx.md) (search by name, filter by accepted input).
