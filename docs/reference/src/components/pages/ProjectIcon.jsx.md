# ProjectIcon.jsx

Source: [`src/components/ProjectIcon.jsx`](../../../../../src/components/ProjectIcon.jsx)

Project icon components, reading the image through [projectIcons.js](../../lib/projectIcons.js.md).

- `ProjectIcon` (default export): the project's icon as an `<img>`, or `fallback` when it has none. `className` replaces the default shape (slightly rounded corners, whole image).
- `ProjectAvatar`: the round avatar of a project, its icon or the first letter of its name, with the accent border when it is the open project.
