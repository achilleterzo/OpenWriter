# FindBar.jsx

Source: [`src/components/FindBar.jsx`](../../../../../src/components/FindBar.jsx)

Find and replace bar for the editor. Live highlight of all matches through the search extension, match counter, case sensitivity, whole words, regular expressions with `$1` group replacements, replace-current and replace-all (single undoable operation), and open/close requests driven by `Ctrl+F` and `Ctrl+H`.
