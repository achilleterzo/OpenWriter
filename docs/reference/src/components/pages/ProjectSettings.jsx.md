# ProjectSettings.jsx

Source: [`src/components/ProjectSettings.jsx`](../../../../../src/components/ProjectSettings.jsx)

Settings screen section for the current project: project name, assistant languages (assistant language and document language), free-text assistant context stored in `context.md`, automatic versioning toggle, project-level spell-check languages, and the project's writing skills with the ones active by default ([SkillsManager.jsx](SkillsManager.jsx.md)). Copying the context from another project also copies its skills. Saved through the project settings IPC.
