# NotesPanel.jsx

Source: [`src/components/NotesPanel.jsx`](../../../../../src/components/NotesPanel.jsx)

Anchored notes for the active document. Lists comments and suggestions with author and status; supports resolve, reopen, accept, and reject of suggestions (applying their replacement to the editor), deletion, and re-anchoring after text changes through the anchoring helper. Notes created by the assistant appear with the same controls.
