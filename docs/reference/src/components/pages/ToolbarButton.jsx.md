# ToolbarButton.jsx

Source: [`src/components/ToolbarButton.jsx`](../../../../../src/components/ToolbarButton.jsx)

Shared toolbar building blocks.

- `ToolbarButton`: an icon button with an accessible label and a tooltip, an active state (accent background) and a hover style.
- `ToolbarDivider`: a vertical separator between toolbar groups.
- `ToolbarGroup`: a group of controls drawn with a separator at its end; when the toolbar wraps, it breaks between groups and never inside one, and the separator disappears after the last group.
