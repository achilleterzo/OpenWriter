# Switch.jsx

Source: [`src/components/Switch.jsx`](../../../../../src/components/Switch.jsx)

An on/off switch, used in place of check boxes across the settings and panels. Props: `checked`, `onChange(value)` (receives the new state), `disabled`, `label` (the accessible name), `title` and `className`. It is a `role="switch"` button, so it can sit inside a `<label>` and a click on the text operates it.
