# Segmented.jsx

Source: [`src/components/Segmented.jsx`](../../../../../src/components/Segmented.jsx)

A group of buttons for a single choice (radio), used in the settings: `label` (also the accessible name of the group), `options` as `[{ value, label }]`, the current `value` and `onChange`. The chosen option is filled with the accent colour; the group is exposed as a `radiogroup` with `aria-checked` on each button, and wraps when the labels are long.
