# DocumentPane.jsx

Source: [`src/components/DocumentPane.jsx`](../../../../../src/components/DocumentPane.jsx)

Editor surface for one document. Each tab mounts its own Tiptap editor, so undo history and scroll position stay per document; the component is hidden when its tab is not active.

The editor is configured with the content and content type of the tab (Markdown, HTML, or the paragraphs extracted from a PDF), is read-only when `tab.readOnly`, and combines: [imageExtension.js](../../lib/imageExtension.js.md) with [imagePaths.js](../../lib/imagePaths.js.md) (sources resolved, base64 allowed), StarterKit with the paragraphs, headings, lists, blockquotes, links and code replaced by their variants, [textAlignExtension.js](../../lib/textAlignExtension.js.md) (aligned paragraphs, headings and HTML blocks), [alertExtension.js](../../lib/alertExtension.js.md), [listItemExtension.js](../../lib/listItemExtension.js.md), [markExtensions.js](../../lib/markExtensions.js.md) (safe marks and the italic delimiter), headings H1–H7, task lists, GFM tables (without them, rows with `|` vanished on opening and therefore from the file on save), the raw-text extensions ([rawMarkdownExtensions.js](../../lib/rawMarkdownExtensions.js.md), [footnoteExtensions.js](../../lib/footnoteExtensions.js.md), [mathExtensions.js](../../lib/mathExtensions.js.md)), Markdown, [smartDashesExtension.js](../../lib/smartDashesExtension.js.md), the note and bookmark decorations ([annotationExtension.js](../../lib/annotationExtension.js.md), [bookmarkExtension.js](../../lib/bookmarkExtension.js.md)), [searchExtension.js](../../lib/searchExtension.js.md), [keepSelectionExtension.js](../../lib/keepSelectionExtension.js.md), and [pendingChangesExtension.js](../../lib/pendingChangesExtension.js.md).

- Links open with Ctrl+click, on text and on images alike, showing where they point in the tooltip; `Ctrl+K` asks the selection bar to edit or insert a link; a plain click keeps placing the cursor.
- Dirty tracking: every update marks the tab; after a pause the content is compared with the Markdown at the last save, and a document that has come back to it (an undo) turns clean again. Any interaction clears the preview state of the tab.
- Images: picked from disk, pasted from the clipboard, or dropped on the editor; a file that the document cannot already reach (next to it or inside the project) is imported next to the document, in its `images/` folder.
- Assistant edits still on hold in an earlier session are restored as soon as the editor is ready; accepting or rejecting one is also saved to the session, so the review does not come back.
- Markdown source view ([SourceEditor.jsx](SourceEditor.jsx.md)): the raw Markdown, applied to the editor after a pause in typing (and re-read when the document changes elsewhere, for instance through the assistant), with "Copy all"; notes, the assistant and find stay on the visual editor.
- Find bar (`Ctrl+F` / `Ctrl+H` or the toolbar button) opens only in the active document, in find or replace mode, and receives the focus on each new request.
- A banner above the editor counts the assistant edits still to review and offers "Accept all" and "Reject all"; [ChangeMarkers.jsx](ChangeMarkers.jsx.md) shows their position along the side, and [SelectionToolbar.jsx](SelectionToolbar.jsx.md) floats above the selection (its "discuss with AI" buttons pass the passage, with the tab title and path, to `onDiscuss`).
- The toolbar also runs the AI-likelihood check and shows its result (`tab.aiScore`).

A pinned tab whose document was closed shows `ClosedDocumentPane` instead: an icon, the title, the source path, and the button that reopens it.
