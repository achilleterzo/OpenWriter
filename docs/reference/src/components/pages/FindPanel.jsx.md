
# FindPanel.jsx

Source: [`src/components/FindPanel.jsx`](../../../../../src/components/FindPanel.jsx)

The look of the Find and Replace bar, without knowing where it searches: the fields, the three options (match case, whole word, regular expression), the previous and next buttons, and the replace row. State and search stay with the caller: [FindBar.jsx](FindBar.jsx.md) (the document editor) and [TextFindBar.jsx](TextFindBar.jsx.md) (the text reader).
