# FileExplorer.jsx

Source: [`src/components/FileExplorer.jsx`](../../../../../src/components/FileExplorer.jsx)

Project file tree. Recursively lists project folders and supported documents, tracks expanded folders, and provides per-item context menus: open, rename (documents keep their extension when omitted), move to the trash with confirmation, reveal in the file manager, and create folder or document entries. Supports drag-and-drop import from outside the project without overwriting existing files, and refreshes on workspace changes.
