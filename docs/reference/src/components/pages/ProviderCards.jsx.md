# ProviderCards.jsx

Source: [`src/components/ProviderCards.jsx`](../../../../../src/components/ProviderCards.jsx)

The AI providers to choose from, as a grid of cards with their logos. The same cards serve the general choice and the choice of a project (the two forms of [AiProviderSettings.jsx](AiProviderSettings.jsx.md), which uses them with `value` and `onChange`).

- `providers` (exported) is the list `[{ value, label, description }]`: `ollama` (Ollama, local or remote HTTP service), `ollama-cloud` (hosted API with an API key), `openrouter` (hundreds of models with one API key), `codex` (native CLI with ChatGPT OAuth), `claude` (native CLI with Claude OAuth) `gemini` (Google AI Studio API key) and `openai` (OpenAI-compatible: LM Studio, llama.cpp, vLLM, Groq, OpenAI and others). The labels are not translated, the descriptions are.
- The component takes `items` (the providers to show, all by default), `onRemove` (a cross on every card but the chosen one), `icons` (custom icons that replace the logos), `onPickIcon(provider, file)` and `onResetIcon(provider)`, and `labels` (names that replace the default ones: the custom provider shows the name the user gave it). On a custom provider the button that changes the icon sits on top of the icon itself, away from the remove cross so that the two cannot be mistaken: it covers the logo with exactly the same background as every logo's square (`bg-stone-100`) in every state, hover included, so that only the sign shows on the icon's own background; the pointer changes the colour of the sign only and shows only while the pointer is over the logo (or the button has the keyboard focus), and, when the icon was changed, a restore button of the same size, background and sign sits next to it (the card's text slides one button to the right while the pointer is over the logo, so that it is not covered). The cross to remove a card is vertically centred on the right, 20 px, and shows on hover or keyboard focus; the icon-only buttons have no border or background and take the accent colour on hover.
- `serverCard` (exported) is the "OpenAI-compatible" entry of the "+" menu; the compatible servers themselves are cards built from the settings, with the generic logo unless the user gave them an icon.
- `logos` (exported) maps each value to its SVG in `src/assets/provider-logos/`; Ollama Cloud reuses the Ollama logo.
- The component is a `radiogroup` labelled "AI provider": one button per provider, `role="radio"` with `aria-checked`, two columns from the `sm` breakpoint. The chosen card gets the teal border and tint; the others stay grey and light up on hover. Each card shows the logo on a light rounded square (decorative, `aria-hidden`), the name in bold and the description in small type, both truncated.
- `onChange(value)` is called with the provider of the card clicked; the component holds no state.

`AiProviderSettings` also uses `providers` on its own, to fill the selector of the research model, filtered to the providers with native tool calls (`RESEARCH_PROVIDERS`).
