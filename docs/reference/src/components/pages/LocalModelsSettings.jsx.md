# LocalModelsSettings.jsx

Source: [`src/components/LocalModelsSettings.jsx`](../../../../../src/components/LocalModelsSettings.jsx)

Settings section for the models that run on this computer: downloaded once, kept in the app data (never in a project) and used by a project only if it asks for them in its own settings. Each model is a card in the `models` list (a new model, for vision, images or audio, is a new entry with the same card): name, description, state, a progress bar while downloading, the **Use this model** switch, and the **Download** / **Remove** buttons.

For now the only model is the one of the search by meaning (see [semantic-pack.cjs](../../../electron/semantic-pack.cjs.md)), which can run on the **CPU** or on the **graphics card** (WebGPU, experimental): the **Calculate with** choice has a row per device (`PackRow`) with its own state, progress bar and **Download** / **Remove** buttons, because each device has its own pack and its own vectors in the index ([gpu-context.cjs](../../../electron/gpu-context.cjs.md)): switching only computes what the other lacks. The graphics card row is disabled when WebGPU is not supported (the reason is shown) and says which card it is (`probeGpu`, asked once when the page opens); if the card failed in this session the page says why and that the CPU is being used until the card is chosen again. A line says which device is in use. Calls: `getSemanticStatus` (polled every 4 s, every second while downloading), `installSemanticPack(directory, device)` (nothing is downloaded unless the user clicks), `removeSemanticPack(directory, device)` (removes the pack and that model's vectors), `setSemanticDevice` and `setSemanticEnabled`, the global switch: off, no project uses the model and nothing is computed even if it is installed (preference `openwriter.localModels.embeddings`). This is the only place where the search by meaning is decided: [ProjectSettings.jsx](ProjectSettings.jsx.md) only shows a status line (every project with its index on is included; to leave one out, turn its index off).

`SemanticModelPicker` (exported) is the choice itself: the "Use this model" switch, CPU or graphics card, download and removal, with the status polling. The settings page wraps it in its card; [FirstRunModelsDialog.jsx](FirstRunModelsDialog.jsx.md) shows it in the first-run window.
