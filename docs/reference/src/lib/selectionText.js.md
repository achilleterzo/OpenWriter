# selectionText.js

Source: [`src/lib/selectionText.js`](../../../../src/lib/selectionText.js)

- `selectedText(editor)`: the plain text of the editor selection, with blocks separated by a blank line; an empty string when the selection is empty. Used by [AiChatPanel.jsx](../components/pages/AiChatPanel.jsx.md) for the selection sent with a request and by [SelectionToolbar.jsx](../components/pages/SelectionToolbar.jsx.md) for the passage to discuss.
