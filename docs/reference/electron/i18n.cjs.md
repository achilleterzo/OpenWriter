# electron/i18n.cjs

Source: [`electron/i18n.cjs`](../../../electron/i18n.cjs)

Translation helper for the main process, aligned with the renderer runtime (`src/i18n/index.js`): the translation keys are the English texts, so English works as source and fallback. It loads the shared catalogs from `src/i18n/locales/` (it, es, fr, de, pt), strips translation-context suffixes (`"Medium|width"`), interpolates `{name}` placeholders, and is used for menus, dialogs, and errors. The active locale (`en` by default, remembered across sessions) is set from the renderer through the `i18n:set-locale` IPC.
