# electron/preload.cjs

Source: [`electron/preload.cjs`](../../electron/preload.cjs)

Secure bridge between the renderer and the main process, exposed as `window.electronAPI` through `contextBridge`. One function per IPC channel, grouped by concern: documents (open, open-path, reopen), sessions (load, save, synchronous save on unload), workspace (import, rename, delete, reveal, create entry, directory listing, project get/open/create/choose/remove/list), project settings and spell checking, document history, conversations and attachments, notes, assistant file tools (list/read/create/move/delete), memory operations, the `skills` namespace (list, get, save, remove, parse, openFolder, setActive, importFile), images (fetch, read, pick, import, screenshots), exports (DOCX/PDF), i18n locale, and the AI namespace: settings, status, provider login and code submission, model listing and accepted inputs per model (`listModelInputs`), encrypted API key presence and storage, non-streaming `chat`, `getCapabilities`, chat attachments (`pickAttachments`, `readAttachment`, `prepareImage`), and `chatStream` (per-request id, streamed `text`/`thinking`/`status`/`usage` events, and `cancel()`). Event subscriptions: `onEditContextMenu`, `onAppCommand`, and `onDocumentCommand`; dropped files are resolved to paths through `webUtils.getPathForFile`.
