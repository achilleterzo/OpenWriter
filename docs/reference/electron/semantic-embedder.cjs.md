# electron/semantic-embedder.cjs

Source: [`electron/semantic-embedder.cjs`](../../../electron/semantic-embedder.cjs)

Turns texts into vectors that represent their meaning (embeddings), with the model of the semantic pack ([semantic-pack.cjs](semantic-pack.cjs.md)): multilingual-e5-small, 384 numbers per text. It runs on WebAssembly (`onnxruntime-web`, Node build, up to 4 threads). The runtime executes the inference **in the thread that calls it**, so it must never be the index thread: `createThreadedEmbedder` (same interface) puts it in its own thread ([semantic-embedder-worker.cjs](semantic-embedder-worker.cjs.md)) and the index worker ([knowledge-worker.cjs](knowledge-worker.cjs.md)) only awaits messages, staying free for search, status and updates while the model works. In Node `fetch` does not read `file://`, so the WebAssembly is passed in memory and only the thread bootstrap module is given by URL.

`createEmbedder({ directory, threads })` returns `{ dimensions, embed(texts, kind), close() }`. `kind` is `'passage'` (what is indexed) or `'query'` (what is searched): E5 needs the prefixes `passage: ` / `query: `. Texts are cut to 4,000 characters **before** tokenizing (the model reads 512 tokens, about 2,500 characters): a huge passage, such as a line of hundreds of thousands of characters, made the tokenizer overflow its stack in Chromium (`Maximum call stack size exceeded` in the GPU context) and cost time for nothing. Then over 512 tokens they are cut keeping the end symbol. The vectors are mean-pooled over the real tokens and normalized to length 1, so the similarity of two texts is their dot product. Speed (measured, 4 threads, 16-core machine): about 60 ms for a passage of 60 words and about 290 ms for one of 250 words (linear in length; more threads or a bigger batch do not help). A project of ~4,500 passages takes some 15 to 20 minutes the first time, in the background; later only changed passages are recomputed. Native onnxruntime would be roughly twice as fast but needs a native library per platform.

Tested with the real model in [tests/semantic-search.test.cjs](../../../tests/semantic-search.test.cjs) (runs only if `OW_SEMANTIC_PACK` points to an installed pack).
